# Design decisions — LOCKED register

> **Scope:** LOCKED — the dated register of user-locked decisions. One line
> per decision, pointing at the spec/code that implements it. Entries change
> only by the user's say-so; new decisions are APPENDED with their date.

Docs disagree → `docs/INDEX.md`'s owner assignment wins; doc disagrees with
code → code wins (except here: an UNBUILT entry is a promise, not a bug).

| 2026-08-04 | **First to fall loses** — every damage is dealt or taken FIRST, so combat ends at the exact APPLICATION that wipes a side and later same-step effects never apply: no DoT/attrition/fatigue tick after the killing blow, no bleed tick on a performer whose cast just won, no lifesteal-back off a killing blow. Application order: a cast's effects in authored order → the performer's bleed; burn at turn start, poison at turn end; attrition ascending initiative score, fatigue canonical order (both stop mid-sweep). Supersedes the 2026-07-30/31 mutual-wipe tempo tiebreak (now unreachable, kept as a documented defensive fallback). Consequence: a perfectly mirrored fight goes to the ENEMY — the player's unit is first in canonical order, so it falls first | `sweep`/`decideOutcome` (`src/engine/combat/simulate.ts`), `applyCast` (`src/engine/combat/interpreter.ts`), `anySideWiped` (`src/engine/combat/state.ts`), `tests/engine/outcomeRule.test.ts` |
