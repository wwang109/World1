Covers which content JSON and generated docs are hand-authored vs
script-generated, and which script owns regeneration. Owner: the authoring
contract for the JSON documents is `src/data/content/README.md`; each row
below names the script that owns its file.

Never hand-edit a generated file, and regenerate only through its owning script.
Proof of idempotency is **regenerate + `git diff --stat`**: run the owning
script on a clean file and the diff must be empty. `npm run content:validate`
additionally recompiles the event packs and re-renders the wiki, and refuses a
stale `events.v3.json` or `docs/generated/event-catalog.md`; `npm run build`
runs it first.

| File | Authored / generated by |
|---|---|
| `src/data/content/skills.v1.json` | **hand-authored** (live; loaded by `src/data/skillsContent.ts`, re-exported by `src/data/skills.ts`) |
| `src/data/content/gems.v1.json` | **hand-authored** (live; `src/data/gemsContent.ts`) |
| `src/data/enemies.ts`, `src/data/modifiers.ts` | **hand-authored**, and still the *live* sources |
| `src/data/content/enemies.v1.json`, `src/data/content/modifiers.v1.json` | generated — `npm run content:export` (`scripts/exportEnemies.ts`, `scripts/exportModifiers.ts`) |
| `src/data/content/event-packs/*.json` | **hand-authored** |
| `src/data/content/events.v3.json` | generated — `npm run content:events` (`scripts/eventPackCompiler.ts`); staleness caught by `npm run content:validate` |
| `src/data/content/events.v2.json`, `src/data/content/events.v1.json` | **frozen** compatibility artifacts — do not touch |
| `src/data/content/event-discoveries.v1.json` | **hand-authored** |
| `docs/generated/event-catalog.md` | generated — `npm run content:wiki` (`scripts/generateEventCatalog.ts`); staleness caught by `npm run content:validate` |
| `public/game-art/**` | generated from `art-src/` by `npm run art:encode`, and **committed** (`npm run build` does not encode) |
| `tests/engine/fixtures/outcomeBaseline.json` | **orphan** — still written by `tests/engine/fixtures/captureOutcomeBaseline.ts`, but nothing reads it since the suite was deleted. Do not regenerate it as evidence; determinism is the same-seed fight diff (`references/verification.md`) |

`npm run scaffold:card` writes nothing — it *prints* a card block to paste.
