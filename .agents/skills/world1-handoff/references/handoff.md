# Finishing or pausing

Follow `CLAUDE.md` for evidence, user confirmation, and publication permission.
The coordination owner is `docs/coordination/session-orchestration.md`.

Report changed paths, commands actually run and their results, remaining work,
and blockers in the current conversation. Distinguish unverified behavior.
Independent review is optional when requested or useful, not a completion gate.

Only genuinely interrupted or multi-session work may need a short task-local
handoff; [optional notes](ledger.md) describes it. No global board, ownership
record, or mandatory report file is part of finishing.
