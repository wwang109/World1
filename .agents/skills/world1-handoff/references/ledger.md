# Optional task-local notes

Use only when interrupted or multi-session work benefits from durable continuity.
The owner is `docs/coordination/session-orchestration.md`.

A short note can record current state, changed paths, verification evidence,
unfinished work, and the next action. Read only the note supplied for the task.
Routine work needs no task ID, ledger, brief/report files, or heartbeat.
Do not read or recreate the retired global board. Leave historical records
untouched; ignored local notes do not automatically travel to another clone.
